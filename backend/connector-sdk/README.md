# Connector SDK

The Connector SDK provides a standard interface for building custom connectors for the AEV platform. It includes shared models and implementations in Python and TypeScript to help connectors follow a consistent contract.

## Getting Started

New to the Connector SDK? Start with the **[Connector SDK Developer Guide](CONNECTOR_SDK_GUIDE.md)**.

The guide explains how to:

- Understand the SDK structure and connector contract.
- Build a connector using the sample implementation.
- Configure credentials and connector settings.
- Run and test a connector.
- Package a connector using Docker.
- Register a custom connector.

## SDK Components

- **Python SDK** — Connector interface and shared data models.
- **TypeScript SDK** — TypeScript implementation of the connector contract.
- **Sample Connector** — Reference implementation to help developers get started.
- **Sandbox and Registration** — Tools and workflows for testing and registering custom connectors.

## Before Contributing

Ensure your connector follows the SDK contract, add tests for its behavior, and verify that the relevant tests pass before submitting your changes.
